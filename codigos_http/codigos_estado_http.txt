CODIGOS DE ESTADO - HTTP

2.. EXITOSO 

    200 OK
    . Petición procesada con éxito devolviendo respuesta.
    . Ejemplos ...
        - Búsqueda de un libro por ID o filtrado exitoso.
        - Registro de entrada o salida en la Bitácora RFID concedido.
        - Devolución exitosa de un libro.
        - Modificación exitosa de los datos de un libro.

    201 Created
    . Petición tuvo éxito y como resultado se CREÓ un nuevo recurso en la BD.
    . Ejemplos ...
        - Registro de un libro nuevo en el catálogo.
        - Creación de un nuevo registro de préstamo de un libro a un alumno.
        - Registro inicial de un usuario o visitante en el sistema.


4.. ERRORES DEL USUARIO

    400 Bad Request
    . Petición enviada contiene: datos inválidos, incompletos o mal formateados.
    . Ejemplos ...
        - Falta un campo obligatorio en el JSON (por ejemplo: no enviaron el título del libro).
        - Mapeo de datos incorrecto (enviaron letras en un campo numérico como la cantidad de stock - strings en campos numericos (int) o viceverza).
        - Intento de préstamo cuando el usuario ya superó su límite de libros permitidos (por ejemplo el usuario ya tiene 4 libros fuera de las instalaciones).
        - Intento de borrar o editar el RFID (id) de un libro que actualmente está en préstamo.

    401 Unauthorized
    . Falta autenticación. El cliente no ha iniciado sesión o no envió un Token (JWT) válido.
    . Ejemplos ...
        - Intentar acceder a rutas administrativas del Back sin un token de sesión activo.

    403 Forbidden
    . El cliente está autenticado pero NO tiene permisos o el acceso está denegado por regla de negocio. (lógica)
    . Ejemplos ...
        - Alumno / docente - servidor / visitante ... intenta ingresar por la puerta RFID pero su estado : es "SUSPENDIDO" o "DADO DE BAJA".
        - Un usuario con rol "Alumno" intenta eliminar un libro del sistema.

    404 Not Found
    . El recurso solicitado no existe en la base de datos.
    . Ejemplos ...
        - Se busca o intenta editar un libro con un ID que no está en la BD.
        - Se escanea un Tag - RFID que no pertenece a ningún libro ni usuario registrado.
        - La ruta solicitada en la URL de la API (endpoint) no existe.

    409 Conflict
    . La petición entra en conflicto con el estado actual de la base de datos (datos DUPLICADOS).
    . Ejemplos ...
        - Intentar registrar un libro con un Tag RFID o ISBN que ya está asignado a otro ejemplar.
        - Intentar registrar un alumno con un número de cuenta (matricula) o Tag - RFID que ya existe.


5.. ERRORES DEL SERVIDOR

    500 Internal Server Error
    . Un error no esperado en el código del servidor o fallo crítico no controlado.
    . Ejemplos ...
        - Captura de excepciones en el bloque `catch` por variables `null` o errores de código impredecibles.
        - Desconexión repentina con la base de datos local durante una consulta.

    503 Service Unavailable
    . El servidor o un servicio dependiente no está disponible temporalmente.
    . Ejemplos ...
        - La base de datos local o el servicio de colas de eventos no responde por saturación de red institucional.
